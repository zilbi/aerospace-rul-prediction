# Safety-Aware RUL Prediction: Прогнозирование остаточного ресурса авиадвигателей ✈️

## Обзор проекта
Данный проект посвящен разработке системы предиктивного технического обслуживания (Predictive Maintenance) для авиационных турбовентиляторных двигателей. Цель проекта — прогнозирование остаточного ресурса (Remaining Useful Life — RUL) на основе многомерных сенсорных данных датасета NASA C-MAPSS.

В отличие от классических подходов, ориентированных на минимизацию средней ошибки, наше решение использует **архитектуру с учетом безопасности (Safety-Aware)**. Мы минимизируем риск переоценки ресурса (overestimation), которая в авиации может привести к эксплуатации неисправного двигателя, что недопустимо с точки зрения безопасности.

## Методология и архитектура
Проект включает следующие этапы разработки:
- **Нормализация данных:** Использование *Baseline Normalization* для устранения различий в начальном износе двигателей.
- **Инженерия признаков:** Генерация агрегированных статистик (скользящие окна, наклон тренда, статистический размах).
- **Вероятностное прогнозирование:** Применение ансамбля квантилей (*Quantile Ensemble*) вместо простого среднего для обеспечения консервативного и безопасного прогноза.
- **Коррекция ошибок:** Применение *OOF Residual Correction* для уточнения прогнозов в критических зонах отказа.

## Структура репозитория
- `/notebooks` — итоговые рабочие тетради (пронумерованные от 01 до 08).
- `/CMAPSSData` — исходный набор данных NASA C-MAPSS (FD001).
- `/outputs` — результаты расчетов, метрики и графики.
- `/archive` — история промежуточных экспериментов и тестирования гипотез.
